What the data shows

  1. It levelled and held every time. All five runs reached the firmware's "level" condition (roll and pitch within ±1° for 3 s) 5–6 s after the command, then held steady: roll/pitch scatter ≤ 0.07°, heading within 0.5°.
  2. "Steady but not perfectly level" is expected from a PD controller. To hold level the controller has to push against the leftover gravity torque, and a PD controller can only push by keeping a small error: offset = torque ÷ Kp (Kp = 4.35 mN·m per degree). The measured offsets match that prediction on both axes in every run (bottom-right plot): 0.3–0.8° in pitch, ≤ 0.2° in roll.
  3. If it looked tilted by more than about a degree, that's a reference question, not the controller. "Level" here means the IMU sees gravity straight down. The accelerometer alone agrees with the filter to within 0.05°, so the filter is right about the IMU. If the IMU is mounted slightly tilted relative to the deck, the controller levels the IMU, and the deck stays visibly off by the mounting angle.
  4. The wheels saturate later, as predicted. The leftover torque fell from ≈ 8 mN·m (roll, before the trim) to 1.3–3.3 mN·m, now mostly in pitch, so wheel B (pitch axis) is the one that hits the limit instead of A. With ≈ 20 mN·m·s of storage per axis, 1.3 mN·m gives ≈ 15 s, which matches run 5. The torque dropped from run 1 to run 5 (3.3 → 1.3 mN·m pitch); if you trimmed between runs, that's the trim working.
  5. Heading hold looks strong (requirement 1). The only yaw disturbance is ≈ 0.12 mN·m (the air bearing's slow spin). All four wheels together store ≈ 48 mN·m·s about yaw, enough for roughly 6–7 minutes of heading hold, if roll and pitch didn't fill the wheels first.
  6. The table now rests almost level. Left alone it swings (3.3 s period, unchanged) about roll ≈ −0.2°, pitch ≈ −0.3 to −0.5° in the IMU frame.

Suggested next steps

  • For the heading hold (requirement 1): hold the table's natural rest tilt, not exact level. It now rests within ≈ 0.5° of level, inside ±1°. Holding the rest attitude needs almost no roll/pitch torque, so only the ≈ 0.12 mN·m yaw torque fills the wheels: minutes of hold instead of seconds. This is a small firmware change (take the reference roll/pitch from the measured rest attitude).
  • Measure the IMU mounting offset: put a bubble level or phone inclinometer on the deck with the table at rest, and compare with STATUS roll/pitch. The difference can be added to the firmware as a level trim.
  • Last pitch trim: ≈ 1.3 mN·m left about y (the B–D axis).
  • Optional: raise the wheel speed limit (the motors reach ≈ 160 rad/s at 12 V) for more margin.
