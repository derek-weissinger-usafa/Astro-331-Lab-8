What the data shows

  • Roll and pitch are excellent. Standard deviation 0.02°, total range ±0.09°, and no trend over 37 minutes. That's far inside the ±1° requirement. The 2.28° / −0.95° offset is the support table or the IMU mounting, not drift. The accelerometer update was applied on every sample; it was never rejected.
  • Yaw drifted −17.6° (−27 °/h) while the table sat still. The magnetometer heading, an independent reference, stayed flat (−0.2 °/h trend), so this is purely estimator drift.
  • The drift is the startup calibration's averaging error, as predicted. True z-gyro bias is about −0.0202 °/s, but the filter kept the 3 s calibration value of about −0.0124 °/s. Gravity can't reveal yaw errors, so the filter can't correct the z bias (x and y were learned correctly). The leftover −0.0078 °/s explains the drift exactly. The gyro noise level predicts that a 3 s average is wrong by about 26 °/h, and that a 60 s average would leave about 6 °/h.
  • The gyro itself is good. Angle random walk is 0.6–1.1 °/√h and the bias-instability floor is about 1–3 °/h (Allan deviation). The coarse resolution of the uncalibrated report (0.00195 rad/s = 0.11 °/s per step) is fine once averaged, because the noise is about one step.
  • About a third of gyro samples were lost, and the stream stalled 57 times for 50–330 ms (38 of those over 100 ms), in clusters about 20 s apart. No backlog of samples arrived after each gap, so data was dropped, not delayed. This run can't tell whether the BNO085 or the Teensy (I²C reads or SD-card writes) is responsible. It didn't matter at rest, but a stall over 100 ms while armed trips the IMU timeout and disarms the wheels. If the cause is in the IMU stream, that would interrupt a DEMO SPIN run.
  • The magnetometer is steady with the motors unpowered. Field 45.3 µT; heading noise 0.7° per sample, with no drift. That makes it a strong candidate for the planned gated yaw aid. Whether it survives the motors running still needs to be measured.
  • Accelerometer magnitude reads 0.981 g, about 1.8% low against local gravity. The filter only uses the direction, so this doesn't matter, but it hints at a small scale error.
  • The filter's reported roll/pitch σ grew to 0.39° / 0.88°. That's a reporting quirk: because the table is tilted 2.3°, part of the large yaw uncertainty shows up on the body roll/pitch axes. Actual roll/pitch error stayed around 0.02°.

On x (and y) the filter tracks the true bias, because gravity reveals tilt errors. On z, gravity carries no heading information, so the filter keeps the bias from the 3 s startup calibration (−0.012 °/s). The true value is about −0.020 °/s, and the difference (−0.0078 °/s) integrates to the drift above.

Sensor statistics (raw, at rest)

"Step" is the smallest change the sensor reports, its resolution. Accelerometer x/y resolution is about 0.035–0.039 m/s² (≈ 0.2° of tilt), but the filter averages many samples.

Recommendations

  1. Lengthen the startup gyro calibration from 3 s to about 60 s (table still). Expected yaw drift drops from about 27 °/h to about 6 °/h, roughly 1° every 10 minutes. This is the cheapest and biggest improvement. An on-demand CALIBRATE command would allow recalibrating whenever the table is at rest.
  2. Find the cause of the sample loss and stalls before the first powered DEMO SPIN. Log the BNO085's own sequence numbers and timestamps to tell IMU-side drops from Teensy-side misses. Likely fixes: wire the BNO085 INT pin so the Teensy reads on demand, drop the magnetometer to 25–50 Hz, and make the SD writes non-blocking if they turn out to be the cause. In the meantime, a longer IMU timeout (e.g. 400 ms) would stop false disarms, at the cost of slower detection of a real failure.
  3. Retune the filter's noise settings from these measurements: gyro noise 1×10⁻³ → about 3×10⁻⁴ rad/s/√Hz. Measured accelerometer noise is about 0.002 in unit-vector terms; keep the setting near 0.01 rather than the current 0.036, leaving room for wheel vibration.
  4. Repeat this test with the motors spinning (e.g. all four at a constant SPEED) to see how much the wheels disturb the magnetometer, vibration and accelerometer noise. That decides the gated-magnetometer question.
